# LinkedIn Post Draft

🌍 Built an Interactive Global Prosperity Dashboard — and made it a live web app, not just a screenshot! 📊

Most dashboard portfolio posts show static images. I wanted mine to be something you can actually click, so I built a fully interactive dashboard analyzing 55 years of global development (1952–2007) across 142 countries — and shipped it as a live page anyone can open in their browser.

🔍 Project Highlights
Modeled a country-year dataset in SQL (SQLite), writing views for population-weighted KPIs and year-over-year comparisons
Built the ETL/cleaning layer — deduplication, type casting, schema design
Designed an interactive dashboard with KPIs, slicers, and an animated bubble chart
Built visualizations analyzing global health and economic trends over time

📈 Dashboard Includes
✅ KPI Cards (Population, Life Expectancy, GDP per Capita, Countries Tracked)
✅ Animated bubble chart — GDP vs. life expectancy, play button walks through 1952→2007
✅ Life Expectancy Trend by Continent
✅ Top 10 Countries by Life-Expectancy Gain
✅ Top 10 Fastest-Growing Economies
✅ Population Share by Continent
✅ Interactive Filters, Slicers & Sortable Country Explorer Table
